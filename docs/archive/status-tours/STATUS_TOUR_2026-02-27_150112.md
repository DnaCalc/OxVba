Profile: mvp-error-state-v11

## Objective
Introduce first explicit runtime error-state behavior aligned with On Error Resume Next semantics.

## New statements
- On Error Resume Next
- Error <code>
- expression support for Err.Number

## Bytecode/VM additions
New ops:
- SetOnErrorResumeNext
- RaiseError { code }
- LoadErrNumber { slot }

VM state additions:
- on_error_resume_next: bool
- last_error: i32

Execution rules in this subset:
- default mode: RaiseError returns runtime error (execution stops).
- resume-next mode: RaiseError updates last_error and continues.
- LoadErrNumber reads last_error into a target slot.

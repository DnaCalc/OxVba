# OxVBA Status Tour (v9 Parameters)

Timestamp: 2026-02-27
Profile: mvp-params-v9

## Objective
Introduce explicit parameter passing semantics for procedure calls.

## Language support added
- Procedure signatures now parse parameter lists with modifiers:
  - ByVal
  - ByRef
  - implicit ByRef default
- Call sites can pass argument lists via Call Name(arg1, arg2, ...).

## Type system checks
- Procedure arity is validated at compile/typecheck stage.
- ByRef parameters require variable arguments (constants rejected).

## Execution semantics
At call emission:
- ByVal: argument value copied into callee param slot.
- ByRef: caller slot copied into callee param slot before call; callee value copied back after return.

- params_byval.bas -> 1
- params_byref.bas -> 2

## Formal obligations
- FO-V9-001: byval mutation isolation.
- FO-V9-002: byref mutation propagation.
- FO-V9-003: byref argument validity rule.

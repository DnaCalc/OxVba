# OxVBA Status Tour (v6 While Loop)

Timestamp: 2026-02-27
Profile: mvp-while-loop-v6

## Objective
Add Do-family loop control flow with explicit short-circuit exits.

## Language support added
- Do While <cond> ... Loop
- Do ... Loop While <cond>
- Exit Do

## Binding model
BoundStmt now includes:

`
ust
DoWhile { cond: BoundCond, body: Vec<BoundStmt>, post_check: bool }
ExitDo
`

post_check = false represents Do While pre-check loops.
post_check = true represents Do ... Loop While post-check loops.

## Emission model
Emitter now tracks loop-exit patch stacks for nested Do loops.
- Entry condition jumps to loop exit for pre-check loops.
- Post-body condition controls continuation for both loop forms.
- Exit Do emits a deferred jump patched to innermost loop exit target.

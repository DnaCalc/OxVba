# OxVBA Status Tour (v8 Procedures)

Timestamp: 2026-02-27
Profile: mvp-procedures-v8

## Objective
Move from single-body execution to named procedure graphs with explicit call/return behavior.

## Compiler changes
- Resolver now extracts explicit Sub/Function bodies into BoundModule.procedures.
- Added BoundStmt::Call { name }.
- Typecheck validates call targets against known procedure names.
- Emitter now:
  - allocates slot ranges per procedure declarations,
  - emits entry procedure first,
  - appends non-entry procedures with trailing Return,
  - patches CallProc targets after label discovery.

## VM changes
Added bytecode ops:
- CallProc { target_pc }
- Return

VM now carries an explicit return stack (call_stack) and resumes caller PC on Return.

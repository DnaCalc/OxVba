  - Runtime baseline is implemented for deterministic module-level dispatch:
    - static handler dispatch ordering is deterministic (`formal_event_runtime_raiseevent_dispatches_to_withevents_handlers_in_stable_order`),
    - host dispatch bindings hydrate and resolve deterministically (`formal_event_runtime_dispatch_host_event_returns_bound_handlers`).

    - non-default-instance rebinding (`Set src = e1` -> `Set src = e2`) is executable (`formal_event_runtime_withevents_reassignment_rebinds_non_default_instances_deterministically`),
    - explicit clear/rebind (`Set src = Nothing` -> `Set src = e2`) is executable (`formal_event_runtime_withevents_clear_then_rebind_updates_dispatch_membership`),

  - Remaining runtime divergence:
    - full sink-instance graph semantics for multiple sink object instances still exceed the current deterministic object/state model; current lane uses deterministic WithEvents binding storage tokens rather than full VBA object-instance field semantics.

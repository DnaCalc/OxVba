Executive technical readout

  • Compiler and bundle path: a new single-file program was compiled to an OxBundle, the artifact was size-checked, source execution returned 42 plus a string sentinel, and the launcher consumed the compiled bundle.
  • Project model: a fresh two-file project proved module roster loading, qualified cross-module calls, local procedure calls, string coercion/concatenation, VM target execution, JIT-enabled execution, and build serialization.
  • Diagnostics: deliberate editing mistakes were preserved as non-zero external command failures with compiler/runtime diagnostics in stderr logs.
  • Access/Jet COM: where ADOX/ADODB are installed, OxVba activated real COM objects, created an Access/ACE .accdb, created a table, inserted records, selected a row, traversed recordset fields through DispatchInvoke, and surfaced Grace / 99 in the runtime snapshot. This is a live environment-dependent integration, not a mock.
  • Access/Jet mixed imported COM: a second database pass imports real ADO/ADOX type libraries, declares Dim catalog As New ADOX.Catalog and Dim cn As New ADODB.Connection, drives ADODB.Connection.Open/Execute through metadata-backed calls, and explicitly remains mixed because unsupported pieces still use DispatchInvoke.
  • Access/Jet strict natural early binding: a third pass uses no DispatchInvoke in the VBA source: it declares ADOX.Catalog, ADODB.Connection, ADODB.Recordset, and ADODB.Field, then exercises rs.Fields("Name").Value plus rs!Name/rs!Score.
  • Immediate interface: the bounded REPL evaluated project procedures, switched default modules, reset the live runtime session, and emitted a transcript suitable for IDE embedding discussions.

Truth boundaries for Q&A

This showcase does not claim full native AOT compilation or full Office/VBA COM parity. Current executable truth is bytecode plus VM/JIT/fallback behavior; COM traffic here uses the supported late-bound CreateObject/DispatchInvoke bridge plus a mixed imported-COM subset for ADO/ADOX member calls. The strict Access/JET pass now proves natural source syntax for the bounded ADO/ADOX slice, while broader descriptor-backed ABI unification remains in progress. Access/ACE availability is machine-dependent and recorded as blocked rather than fabricated if missing.

# OxVBA Status Tour (v4 Boolean Logic)

Timestamp: 2026-02-27
Profile: `mvp-boolean-logic-v4`

## Profile objective
Extend `If` condition semantics from equality-only checks to full relational operators plus boolean composition (`Not`, `And`, `Or`).

## What changed in compiler binding

`resolve.rs` now models branch conditions as structured condition trees:

```rust
pub enum CompareOp { Eq, Ne, Lt, Le, Gt, Ge }

pub enum BoundCond {
    Compare { op: CompareOp, lhs: BoundExpr, rhs: BoundExpr },
    Truthy(BoundExpr),
    Not(Box<BoundCond>),
    And(Box<BoundCond>, Box<BoundCond>),
    Or(Box<BoundCond>, Box<BoundCond>),
}
```

`BoundStmt` now uses:

```rust
IfCond { cond: BoundCond, then_body: Vec<BoundStmt> }
```

## Bytecode/VM expansion

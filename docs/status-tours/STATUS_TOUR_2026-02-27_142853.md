# OxVBA Status Tour (v7 Select Case)

Timestamp: 2026-02-27
Profile: mvp-select-case-v7

## Objective
Add first-match multi-branch dispatch through Select Case.

## Supported form
- Select Case <expr>
- Case <int>[, <int> ...]
- Case Else
- End Select

## Binding shape
BoundStmt::SelectCase now stores:
- subject expression,
- case arms (Vec<(values, body)>),
- optional else-body.

## Emission approach
Emitter evaluates subject once into a temp slot, then for each arm:
1. Aggregates equality checks across arm constants.
2. Branches to next arm on aggregate false.
3. Executes arm body and jumps to end on match.

This enforces deterministic first-match behavior.

# OxVBA Status Tour (v5 Else Paths)

Timestamp: 2026-02-27
Profile: `mvp-else-paths-v5`

## Objective
Extend branch support from single-path `If ... End If` into full `If ... ElseIf ... Else ... End If` chain behavior.

## Compiler updates
`BoundStmt::IfCond` now carries both branches:

```rust
IfCond {
    cond: BoundCond,
    then_body: Vec<BoundStmt>,
    else_body: Vec<BoundStmt>,
}
```

Resolver behavior:
- `parse_block` terminates on `ElseIf`/`Else`/`End If` when inside `If` body.
- `parse_if_tail` recursively lowers `ElseIf` into nested `IfCond` in `else_body`.
- Plain `Else` body parses until `End If`.

Emitter behavior:
- `JumpIfZero` targets else-entry.
- non-empty `else_body` inserts an unconditional `Jump` over else tail.
- nested `ElseIf` chains compile as linked branch segments.
